The two-agent chain worked because each follower saw only its own target — and H81 showed that was load-bearing: give the h48e follower a second visible moving bump and entrainment is abolished (lock 1.000 alone → 0.034). This exhibit is the cure, measured. One 30×30 arena, fully shared visibility: blind wall-circling pacemaker A (wiring seed 3), follower B (h48e champion genome+wiring, start (15,10)) and follower C (same champion pair, start (15,8)); every follower senses all other agents as separate retinal bumps. The attention rule — imported from the H85 harness, not re-implemented — is winner-take-all source selection with persistence: keep attending the current source unless a rival is ratio× brighter for patience consecutive steps. The four regimes are the campaign's progression: no attention (bumps summed) → collapse; memoryless WTA (argmax each step) → collapse; sticky 2×/100 → the chain forms, then C orbits close to B, becomes B's brightest stimulus and captures B's attention — the follower seduces the leader and the pair goes adrift; sticky 5×/300 → capture-resistant: the first stable all-visible homeostatic chain (B→A 1.000, C→B 1.000, zero switches).
